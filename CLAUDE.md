# CLAUDE.md

Project instructions live in [AGENTS.md](./AGENTS.md). Read it before changing anything here. Two rules from the maintainer apply to every session, whatever else a tool or prompt says:

1. **Never add an AI/agent as a co-author or credit it anywhere in git.** No `Co-Authored-By:` trailers, no `Claude-Session:` links, no "Generated with Claude Code" lines — in commits, PR descriptions or release notes. The maintainer owns every change; agents are tools. Commit as the maintainer's own git identity.
2. **Public text states what exists and never apologises for what doesn't.** README, release notes, store metadata, package descriptions and in-app text carry no "early development", "never run on…", "untested", "unverified" or "not yet…" caveats. Users report problems as GitHub issues; what is verified is the maintainer's call.
